# Final Conflict 압축 구조 조사

상태: 진행 중

검증일: 2026-07-29

## 확정한 사실

영어 참조 패치 fcpatch_070706.ips 자체만 분석했습니다. 원본 ROM이나 미리 패치된 ROM은 내려받지 않았습니다.

- IPS 크기: 47,290바이트
- IPS SHA-256: 3cc1085508c7298d5d20fbfefec929cdfdadbcd60340a66ec0e4c2aa92d48c07
- 레코드: 288개, 일반 271개와 RLE 17개
- 변경 데이터: 46,261바이트
- 가장 높은 기록 끝 위치: 0x80000
- 큰 압축 데이터 구간:
  - 0x203D2..0x23BBF, 14,317바이트
  - 0x2401F..0x2702A, 12,299바이트

## Huffman 트리

- 벡터 파일 오프셋: 0x29C3F
- ROM 논리 주소: 0x5C3F
- 벡터: 16비트 little-endian 포인터 256개, 512바이트
- 비어 있지 않은 트리: 221개
- 0xFFFF인 빈 엔트리: 35개
- 첫 포인터: 0x5E40
- 벡터와 트리/심벌 데이터는 영어 IPS 레코드만으로 전부 복원됩니다.

트리 구조는 MSB 우선 비트열입니다. 1은 잎, 0은 두 자식을 가진 노드입니다. 잎 심벌은 구조 비트열 바로 앞에 역순으로 저장됩니다. tools/sfgfc_huffman.py 는 소비하는 모든 바이트가 IPS에서 제공됐는지 마스크로 확인합니다.

## 기본 문자 코드

| 코드 | 의미 |
|---:|---|
| 0x01 | 공백 |
| 0x02..0x0B | 숫자 0..9 |
| 0x0C..0x25 | 영문 대문자 A..Z |
| 0x26..0x3F | 영문 소문자 a..z |
| 0xD0 | 줄/페이지 제어 후보 |
| 0xC9 | 엔트리 초기/종료 심벌 후보 |

0xC9 트리는 181개 출력 잎을 가지며 후보 압축 시작점에서 0xC9로 시작해 0xC9로 종료되는 사례가 반복됩니다. 실제 조회표가 확정되기 전까지는 후보로 유지합니다.

## 아직 확정하지 않은 항목

1. 1,492개 실제 스크립트 엔트리를 가리키는 조회표와 뱅크 규칙
2. 0x80 이상 심벌의 단어 사전과 확장 규칙
3. 목표 인트로 문장의 정확한 엔트리 ID와 시작 비트 오프셋
4. 한국어 v5.1에서 변경된 트리와 새 스크립트 영역의 소비 코드

압축 뱅크의 모든 바이트를 엔트리 시작으로 가정하면 수천 개의 거짓 양성이 생깁니다. 조회표 없이 읽기 쉬운 문자열이 나온 것만으로 디코더 완료를 선언하지 않습니다.

## 한국어 v5.1과의 관계

v5.1 BPS는 영어 벡터 위치 512바이트 중 487바이트를 명시적으로 덮어씁니다. 그중 416바이트가 영어 벡터와 다르고 25바이트는 원본 의존 SourceRead입니다. 영어 벡터를 한국어 ROM에 그대로 대입할 수 없습니다. S25U 원본에 v5.1을 적용한 뒤 한국어 대상 ROM의 벡터, 조회표, 사전을 별도로 추출해야 합니다.

## 디코더 완료 조건

1. 조회표에서 엔트리 포인터를 읽습니다.
2. 이전 심벌별 트리로 비트를 디코딩합니다.
3. 단어 사전을 확장합니다.
4. ROM에서 And so began Mishaela's new ambition... 을 정확히 재현합니다.
5. 왕복 인코딩 결과가 소비 코드와 일치하는지 검증합니다.

참고 구현 코드는 복사하지 않았습니다. 기록된 형식과 실제 Final Conflict IPS 바이트를 대조해 독립적으로 작성했습니다.
참고 `SFGDecoder`의 조회 항목은 `[bank][address low][address high]` 순서이고
이전 심벌별 트리를 선택하는 문맥 의존 방식입니다. 이 계열 구조는
v5.1의 `bank_addr_le` 후보를 정적으로 지지하지만, 실제 v5.1 정렬은
후보 압축 주소의 런타임 read와 매퍼 뱅크가 함께 확인될 때만 확정합니다.

## 2026-07-29 v5.1 한국어 엔진 추가 확정

v5.1 BPS의 원본 비의존 확장 데이터를 독립 파서로 다시 읽었습니다.

- 한국어 Huffman 벡터: 파일 0x80100, 뱅크 0x20, 논리 주소 0x4100
- 256엔트리 중 51개 트리, 205개 빈 엔트리
- 역순 잎 심벌과 트리 구조의 정확한 합집합: 0x80300..0x808D3
- 트리 문맥: 0x00..0x20, 0x5F, 0x64, 0xC9, 0xCA, 0xCC, 0xCD, 0xCF, 0xD0, 0xD1, 0xD2, 0xD4, 0xD5, 0xD6, 0xD8, 0xD9, 0xDB, 0xDC, 0xDD
- 한국어 글꼴 런타임: 0x87000..0x8730B와 0x87A00..0x87A9D
- 글꼴 페이지 매핑: 0x87400..0x874F4, 244엔트리
- 글꼴 데이터 뱅크: 0x22..0x5E

이 결과는 analysis/v5_1_engine_layout.md와 tools/v5_1_engine.py에서 재현합니다. 영어판과 한국어판은 문맥 집합과 벡터 위치가 다르므로, 같은 심벌 값을 같은 의미로 간주하지 않습니다. 실제 대사 조회표는 여전히 소비 코드에서 확인해야 합니다.
