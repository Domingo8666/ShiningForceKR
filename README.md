# ShiningForceKR

Sega Game Gear용 `Shining Force Gaiden - Final Conflict` 한국어 패치 재작업 프로젝트.

## 기본 경로

Termux:
```bash
cd ~/storage/shared/ShiningForceKR
```

Android 내 파일:
```text
내부 저장공간/ShiningForceKR
```

## 폴더

- `original/`: 무수정 원본 ROM
- `patch/`: BPS·IPS 등 기존 패치
- `docs/`: 상태 보고서와 인수인계 자료
- `analysis/`: ROM 구조·주소·디코더 분석
- `tools/`: 분석·추출·삽입 도구
- `src/`: 소스 코드
- `script/`: 추출·번역 스크립트
- `font/`: 한글 폰트와 매핑 자료
- `build/`: 생성 ROM과 최종 패치
- `saves/`: 세이브 스테이트
- `evidence/`: 문제 영상과 스크린샷
- `logs/`: 명령 실행 및 테스트 로그
- `backup/`: 수동 백업

## Codex 첫 지시

`CODEX_FIRST_PROMPT.txt` 내용을 그대로 사용한다.
